# Qwerty123 — Менеджер паролей

Десктопное приложение для безопасного хранения, генерации и управления учетными данными. Проект разработан на Python с использованием графического фреймворка PyQt6 и криптографических алгоритмов шифрования.

---

## Основные возможности

* **Надежное шифрование данных:** Все пароли хранятся в зашифрованном виде в локальной базе данных SQLite.
* **Трехуровневый генератор паролей:** Автоматическое создание стойких паролей с использованием модуля secrets без лишних зависимостей.
* **Категоризация записей:** Удобная сортировка и фильтрация сохраненных аккаунтов по категориям с возможностью динамического добавления новых.
* **Быстрое копирование:** Клик по логину, паролю или сайту автоматически копирует данные в буфер обмена.
* **⚡ Плавающая панель (Ctrl+P):** Компактное окно быстрого доступа, которое висит поверх всех окон ОС для мгновенной генерации и копирования паролей.
* **Защита от подглядывания:** Поле пароля замаскировано и раскрывается при наведении курсора.

## Как запустить проект

У вас есть два способа запустить менеджер паролей: с помощью готового скомпилированного .exe файла или из исходного кода.

### Способ 1. Запуск готового .exe файла (для Windows)

Если вам нужно запустить программу на Windows без установки Python и сторонних библиотек:

1. Перейдите во вкладку Actions в верхнем меню этого репозитория: https://github.com/khmelnovz-coder/Qwerty123/actions
2. Кликните на последнюю успешную сборку (с зеленой галочкой) в списке.
3. Прокрутите страницу вниз до раздела Artifacts и скачайте архив Qwerty123-Windows.
4. Распакуйте архив и запустите готовый файл main.exe.

---

### Способ 2. Запуск из исходного кода (для разработчиков / Python 3.12+)

1. Клонируйте репозиторий:
   git clone https://github.com/khmelnovz-coder/Qwerty123.git
   cd Qwerty123

2. Установите необходимые зависимости:
   pip install -r requirements.txt

3. Запустите приложение:
   python main.py

---

### 🔨 Самостоятельная сборка (.exe / binary)

Если вы хотите собрать исполняемый файл самостоятельно с помощью PyInstaller:

# Установка PyInstaller
pip install pyinstaller

# Сборка в один файл
pyinstaller --onefile --noconsole main.py

Готовый исполняемый файл появится в папке dist/.
